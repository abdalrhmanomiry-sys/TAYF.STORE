## 1. نظرة عامة

هذا المشروع متجر إلكتروني (متجر طيف) يتكوّن من:

- **`index.html`** — واجهة المتجر (ما يراه الزوار).
- **`admin.html`** — لوحة التحكم (تظهر فقط لمن يملك كلمة المرور).
- **`netlify/functions/`** — برامج صغيرة على خادم Netlify تحفظ البيانات وتُعيدها.
- **Netlify Blobs** — قاعدة بيانات مدمجة مع Netlify (مجانية تماماً).

**كيف يعمل الحفظ؟**

```
لوحة التحكم  ──(حفظ)──>  Netlify Function  ──>  Netlify Blobs (تخزين دائم)
                                                       │
الموقع للزوار  <──(قراءة)──  Netlify Function  <───────┘
```

أي تعديل تجريه في لوحة التحكم يُحفظ على خادم Netlify ويظهر **لجميع الزوار حول العالم** فور تحديث الصفحة.

## 3. بنية المشروع

```
tayf-store/
│
├─ index.html                    ← صفحة المتجر للزوار
├─ admin.html                    ← لوحة التحكم
├─ data-default.json             ← البيانات الافتراضية (عند أول تشغيل)
├─ package.json                  ← اعتماديات Netlify Functions
├─ netlify.toml                  ← إعدادات Netlify
├─ .gitignore
├─ README.md                     ← هذا الملف (دليل النشر)
├─ دليل-الاستخدام.md            ← دليل استخدام لوحة التحكم

    └─ functions/
        ├─ data.js               ← API قراءة وحفظ البيانات
        └─ login.js              ← API التحقق من كلمة المرور
```

## 4. إنشاء حساب GitHub ورفع المشروع

### 4.1 إنشاء حساب GitHub

1. افتح: https://github.com/signup
2. أدخل بريداً إلكترونياً، كلمة مرور، واسم مستخدم (مثلاً: `your-name`).
3. أكمل التحقّق وفعّل الحساب من بريدك.

### 4.2 إنشاء مستودع (Repository) جديد

1. بعد تسجيل الدخول، اضغط زر **`+`** أعلى يمين الصفحة → **New repository**.
2. املأ:
   - **Repository name**: `tayf-store` (أو أي اسم تريده).
   - **Description**: `My online store` (اختياري).
   - اختر **Public** (مجاني وأسرع لـ Netlify).
   - **لا تضع علامة** على Add README / .gitignore / license (لأن المشروع عندنا جاهز).
3. اضغط **Create repository**.

ستظهر صفحة فيها أوامر — تجاهلها مؤقتاً، سنرفع المشروع من المتصفح مباشرة (الأسهل).

### 4.3 رفع ملفات المشروع (بدون أوامر، عبر المتصفح)

> هذه الطريقة الأسهل لمن لا يستخدم Git.

1. في صفحة المستودع الفارغ، اضغط على الرابط **uploading an existing file** (أو اذهب إلى **Add file → Upload files**).
2. **اسحب جميع ملفات المشروع** من مجلد `tayf-store` إلى نافذة المتصفّح.

   > ⚠️ **مهم جداً**: يجب رفع الملفات **مباشرة** وليس داخل مجلد. أي بعد الرفع يجب أن ترى في GitHub:
   > - `index.html`
   > - `admin.html`
   > - `netlify.toml`
   > - `package.json`
   > - مجلد `netlify/` (بداخله `functions/`)
   > - باقي الملفات
   >
   > **وليس** مجلداً واحداً اسمه `tayf-store` فيه كل شيء.

3. في خانة **Commit changes**، اكتب رسالة مثل: `Initial upload`.
4. اضغط **Commit changes** (الزرّ الأخضر).

✅ المشروع الآن على GitHub.

## 5. إنشاء حساب Netlify وربطه بـ GitHub

### 5.1 إنشاء حساب Netlify

1. افتح: https://app.netlify.com/signup
2. اختر **"Sign up with GitHub"** (هذا أسهل خيار لأنه سيربط الحسابين تلقائياً).
3. اقبل صلاحيات الربط.

### 5.2 إنشاء موقع جديد من المستودع

1. في لوحة Netlify، اضغط **Add new site → Import an existing project**.
2. اختر **Deploy with GitHub**.
3. أعطِ الإذن لـ Netlify بالوصول إلى مستودعاتك (مرّة واحدة فقط).
4. ستظهر قائمة بمستودعاتك — اختر **`tayf-store`**.
5. في صفحة الإعدادات:
   - **Branch to deploy**: `main` (الإفتراضية).
   - **Base directory**: اتركها فارغة.
   - **Build command**: اتركها فارغة.
   - **Publish directory**: اكتب `.` (نقطة واحدة) أو اتركها فارغة (الإعدادات في `netlify.toml` ستضبطها).
   - **Functions directory**: اتركها كما هي (سيستعمل ما هو في `netlify.toml`).
6. اضغط **Deploy site**.

⏳ سيبدأ النشر — انتظر دقيقتين تقريباً.

### 5.3 الحصول على رابط الموقع

بعد انتهاء النشر، ستحصل على رابط مثل:

```
https://random-name-12345.netlify.app
```

يمكنك تغييره: **Site configuration → Change site name** → اختر اسماً جميلاً مثل `tayf-store`.

سيصبح: `https://tayf-store.netlify.app`

## 6. ⚠️ خطوة مهمة جداً: ضبط كلمة مرور لوحة التحكم

> 🚫 **بدون هذه الخطوة لن تستطيع الدخول للوحة التحكم!**

### كيف؟

1. في لوحة Netlify، افتح موقعك (`tayf-store`).
2. اذهب إلى: **Site configuration** (في القائمة الجانبية) → **Environment variables**.
3. اضغط **Add a variable** → **Add a single variable**.
4. املأ:
   - **Key**: `ADMIN_PASSWORD` (انسخه بالضبط، كل الحروف كبيرة، مع `_`).
   - **Values → Value**: اكتب كلمة المرور التي اخترتها (مثلاً: `MyShop@2025!`).
   - **Scopes**: اختر **All scopes**.
5. اضغط **Create variable**.

### ⚠️ مهم: إعادة النشر بعد إضافة المتغيّر

كلّ تعديل لمتغيرات البيئة يتطلّب إعادة نشر:

1. اذهب إلى تبويب **Deploys**.
2. اضغط **Trigger deploy → Deploy site**.
3. انتظر دقيقتين حتى ينتهي النشر.

✅ الآن الموقع جاهز وكلمة المرور مفعّلة.

## 7. الدخول إلى لوحة التحكم لأول مرة

1. افتح: `https://tayf-store.netlify.app/admin.html` (بدّل `tayf-store` باسم موقعك).
2. ستظهر شاشة تسجيل دخول — اكتب كلمة المرور التي ضبطتها في الخطوة السابقة.
3. اضغط **دخول**.

✅ ستظهر لوحة التحكم.

> 🔒 **نصيحة أمنية**: لا تضع رابط `/admin.html` في أي مكان عام. هو رابط سرّي. الزوار العاديون لا يحتاجونه.

## 9. نطاق مخصّص (اختياري)

إذا أردت رابطاً مثل `mystore.com` بدلاً من `tayf-store.netlify.app`:

1. اشترِ نطاقاً من أي مزوّد (Namecheap, GoDaddy, إلخ).
2. في Netlify: **Domain management → Add a domain**.
3. أدخل نطاقك، واتبع التعليمات (تغيير DNS لدى مزوّد النطاق).

> Netlify يعطيك شهادة SSL مجانية (HTTPS) تلقائياً.

## 10. حلّ المشاكل الشائعة

### ❌ "كلمة المرور غير صحيحة"
- تأكّد من أنك أضفت `ADMIN_PASSWORD` بحروف كبيرة في Environment variables.
- تأكّد من أنك **أعدت النشر** بعد إضافة المتغيّر (Trigger deploy → Deploy site).
- تأكّد من عدم وجود فراغات قبل/بعد كلمة المرور.

### ❌ الموقع لا يحمّل المنتجات
- افتح Developer Tools (`F12`) → تبويب Console، وانظر الخطأ.
- في 99% من الحالات: مشكلة في الـ Function `/api/data`. اذهب إلى Netlify → تبويب **Logs → Functions** وانظر السجل.

### ❌ التعديلات لا تظهر للزوار
- تأكّد من ضغط زرّ **💾 حفظ** في لوحة التحكم.
- إذا ظهرت رسالة "تم الحفظ ✓" — افتح الموقع في تبويب آخر **بعد عمل تحديث (Ctrl+F5)**.
- لا تختلط الأمور: الزوّار قد يكون عندهم نسخة قديمة في الكاش — أخبرهم بعمل تحديث.

### ❌ "تعذّر حفظ البيانات"
- غالباً مشكلة في `ADMIN_PASSWORD` — أعد التحقّق من Environment variables.
- جرّب تسجيل خروج ودخول من جديد.

### ❌ صورة منتج لا تظهر
- الرابط يجب أن يبدأ بـ `https://`.
- جرّب فتح رابط الصورة في تبويب جديد للتأكّد من صلاحيته.
- استخدم خدمة استضافة صور مجانية مثل [imgbb.com](https://imgbb.com).

### ❌ Function failed أو 500 Internal Server Error
- اذهب إلى Netlify → تبويب **Deploys** → اضغط على آخر deploy → **Deploy log** لمعرفة سبب الخطأ.
- تأكّد من أن مجلد `netlify/functions/` رُفع بشكل صحيح إلى GitHub.

## 🔄 تحديث المتجر لاحقاً

كل تعديل تجريه في لوحة التحكم **يُحفظ تلقائياً في Netlify Blobs** — لا تحتاج لرفع شيء على GitHub.

GitHub مطلوب فقط إذا أردت **تعديل الكود نفسه** (تغيير الألوان، إضافة ميزة جديدة، إلخ).
